# 图表设计规则

## 从信息重点到画面

先确定本模块要回答的问题、比较关系和论证所需证据，再设计主体、阅读顺序、对齐和强调。图表类型在视觉编码确定后选择，常用实现与定制构图共用同一套视觉规范。

重点须由数据支持。检查完整区间、异常值、分布与不确定性是否会改变判断，明确筛选、排序、聚合和比例计算的依据。

## 硬约束

### 数据、口径与单位

- 使用可追溯的原始数据和明确的派生计算。合成示例显式标注为合成数据。
- 百分比明确分子、分母、去重范围和适用时间窗口。将口径放在报告正文或 `report.description` 中。
- `unit: 'percent'` 的数值使用小数比例。输入 `0.73` 表示 `73%`，有符号贡献中的 `-0.12` 表示 `-12%`。
- 百分比轴每个刻度都带 `%`，数据标签的百分比单位同样完整。
- `null` 表示缺失，`0` 表示真实零值。按实际数据保留两者的区别。
- 轴范围、对齐和尺度必须支持任务所需的比较。双轴分别明确单位，线柱的屏幕高度接近不足以说明其数值相等。

### 整份报告的排版

- 单图占整行，双图按可用行宽扣除图间间隔后分配宽度。
- 单图、双图中的每张图遵循整份报告共同的图高基准，通过 `report.rowHeight` 统一设置。
- 宽度 `1600`、双图各约 `750`、图高 `400` 仅为排版示例。具体尺寸由报告容器、间隔和信息密度决定。
- 图内标题、横轴文字、图例文字以及其他同角色文本，在整份报告中分别保持统一字体和字号。通过报告级 `theme` 设置。
- 容器变窄后重新排布文字和图元，保持角色字号。重排后继续检查整体图高及信息可读性。

### 横轴与附注

- 主轴标签仅允许横排或竖排，严禁斜转。
- “第 N 天”等主标签保留主阅读层级。阶段、活动或特殊背景信息放在对应主标签下方。
- `contexts` 与 `categories` 一一对应，用空字符串表示该节点没有附注。
- 多行附注与节点锚点对齐，为各行文字预留真实高度。

### 信息承接

- 隐藏一侧数值轴时，该轴承载的每个非缺失值均须有对应标签承接读数。
- 必显标注和数据锚点关系在响应式重排后继续成立。
- 同画面组合保留交叉比较所需的节点、尺度与身份关系。分区可以调整位置，共同节点继续对齐。

### 构成与贡献

- `stackMode: 'percent'` 表示完整、互斥的非负构成。各节点输入为比例小数，各部分合计 `1`，入口校验允许浮点误差。
- `stackMode: 'diverging'` 表示正负来源贡献。输入保留原始有符号值，正负分别从零线累积，各节点合计由实际数据决定。
- 正负贡献的含义与完整构成不同。根据业务定义选择相应模式，并注明基准或分母。

## 条件策略

### 常见表达目的

先确定信息重点与画面，再按比较任务选择编码。以下为常见选择，具体构图可继续组合与定制。

| 表达目的 | 常见实现与条件 |
| --- | --- |
| 比较少量数值的高低差异 | 用柱高体现差异，并采用紧凑柱间距 |
| 比较少量趋势的差异 | 用折线体现变化过程和趋势分歧 |
| 交叉比较逻辑相关的不同指标 | 在强逻辑必要性下组合柱与线，维持同节点对应关系 |
| 观察结构分布及异常 | 完整、互斥、非负构成可用百分比堆叠，突出异常组成或结构变化 |

### 多指标组合

强逻辑必要性是组合前提。需要同时观察同节点的人群差异、阈值差异、占比与规模，且这些关系共同回答本模块问题时，可组合在同一画面中。

同一画面允许共享绘图区，也允许组成对齐的区域。选择能让读者直接完成交叉读取的构图。划分区域时维持共同节点和比较尺度的关系。

对于逻辑联系较弱、独立回答不同问题的指标，可分别呈现，并用整份报告的排版规范保持视觉一致。

### 图例

- 精简图例名称，保留区分指标身份所需的信息，并让配色数量与表达任务相称。
- 图例少且总宽度适合主体区域时，横排并居中。
- 图例较多时，放在右侧单列，通过实际文字宽度和可用空间判断。
- 先检查右侧图内是否存在足够空白，确保图例与数据图元清楚分离。
- 图内空间不足时，缩小左侧绘图区，在右侧预留图例区域。
- 容器变窄时可重排图例，保持指标身份和字号，重新测量其占用空间。

### 配色

- 收敛颜色数量，按当前模块的论证重要性分配视觉强调。
- 关键类型常对应极值或剧变，采用高饱和、显眼的颜色。非论据对象采用浅色，形成清楚层级。
- 语义相近的指标采用同色系，需要明确区分的对象采用可辨差异。
- 同一语义身份跨图尽量保持可识别的一致性。当前模块的强调关系需要改变颜色时，说明颜色的作用域，并利用名称、分组或线型维持身份识别。
- 实线、虚线及深浅可共同编码不同维度。编码含义在本图及关联比较区域中保持一致。

### 数据标签

通常减少标签，优先标示极值、异常、剧变及必要读数。依据实际任务决定哪些点值得直接标注。

折线标签通过位置偏移与框线组织，为文字、曲线和相邻标签留出空间，并维持标签与数据点的清楚关联。

一侧数值轴隐藏时，每个非缺失值的对应标签承担读数职责。安排轴与标签时一起检查信息是否完整。

### 纵轴、网格与读数

默认竭力避免同时展示双纵轴。组合指标涉及不同尺度时，先安排能够完整承接读数的标签和隐藏轴方案。确需同时显示双轴时，分别明确单位，并核查对应关系。

多维、多标签场景使用网格辅助读数，减少数值标签，将直接标注集中在极值、异常和剧变等重点位置。

### 柱间距

默认采用紧凑柱间距，让柱体与比较关系成为主体。多系列柱形保持组内联系，组间保留足够区分。依据真实类别数量、柱宽和容器宽度检查密度。

### 响应式重排

右侧说明可以移到底部，并列区域可以上下排列。数据值、单位、对象身份、重点含义、必显内容及标注关联保持一致。

允许调整区域位置、换行、图例排布和刻度密度。横轴主标签及特殊附注继续清楚对应，图内文字沿用报告级字号。

保持多指标交叉比较的可读性。空间不足时，先按已确定的构图关系重新分配区域，仍无法满足时说明具体限制，并与用户确定布局取舍。

## 参考图与验收

参考图提供信息关系、构图和视觉层级的证据。复现时逐项核对数据口径与本规则，修正参考图中漏写百分号等错误。

在整行、半行和窄容器中检查实际截图。选定一个节点，读取多组指标并比较差异，确认读者能准确找到对应值、标注和图例。再核对报告整体的共同图高、字体、字号、颜色作用域和留白节奏。
